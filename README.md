# AI Tools

A personal collection of Claude & AI productivity resources — prompts, workflows, references, and notes.

## Folder Structure

| Folder | What goes here |
|---|---|
| `prompts/` | Reusable prompts for Claude and other AI tools |
| `workflows/` | Step-by-step workflows and automation templates |
| `references/` | Useful content from external repos and articles |
| `notes/` | Personal notes on what works, lessons learned |
